# Exercise 3: GitHub CLI and APIs

## Problem

The users of this repository have not been following the guidelines for creating issues. They are not adding the appropriate labels, and they are not providing all the requested information in the issue template. This is causing confusion and delays in the development process.

Your task is to create a GitHub Actions workflow that uses the GitHub CLI to add a comment on new issues that do not follow the guidelines.

The guidelines are in the [guidelines.md](guidelines.md) file in the `main` branch.

Make sure to use the GitHub CLI to add a comment to the issue. You can find the GitHub CLI documentation [here](https://cli.github.com/manual/).
